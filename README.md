# 🏭 مصنع البودكاست — أسرار و خفايا

مصنع أوتوماتيكي كامل: كتعطيه السكريبت (و بغيتي رابط تصويرة خلفية) و هو كيعطيك
**فيديو بودكاست كامل 1080x1080** بنفس الصوت و نفس الستايل البصري ديال البودكاست الأول:
الاستوديو، الموجة الذهبية، الترجمة المتزامنة بالدارجة، زر اللايك، و بطاقة الاشتراك فاللخر.

---

## 📦 شنو كاين فهاد الباكاج؟

| الملف | الدور |
|---|---|
| `podcast_factory.py` | المصنع الكامل (صوت + ترجمة + فيديو) |
| `requirements.txt` | المكتبات |
| `voice_ref.wav` | **مرجع الصوت** (مقطع من البودكاست الأول — الصوت كيتستنسخ منو) |
| `script.txt` | هنا تلصق نص البودكاست الجديد |
| `assets/` | خلفية الاستوديو + الخطوط |
| `.github/workflows/podcast.yml` | الزر السحري ديال GitHub Actions |

---

## 🚀 الخطوات (مرة وحدة غير للتنصيب)

1. **صايب Repository جديد فGitHub** (سميه مثلا `podcast-factory` و خليه **Public** — الأهم باش Actions يبقى مجاني بلا حدود).
2. **ابلودي محتوى هاد الباكاج كامل** (بنسيو ديجا مفكوك من الzip):
   - من صفحة الريبو: **Add file → Upload files**
   - **سحب المجلد كامل** بما فيه `.github` و `assets` (المتصفح كيحافظ على البنية).
   - تأكد بلي المسار ديال الworkflow هو بالظبط: `.github/workflows/podcast.yml`
3. ✅ صافي التنصيب سالا!

## 🎬 كل مرة بغيتي بودكاست جديد:

1. حلّ `script.txt` فGitHub (قلم ✏️) و **لسق السكريبت الجديد** بدل القديم → Commit.
2. سير لـ **Actions → 🏭 Podcast Factory → Run workflow**:
   - `bg_url`: رابط تصويرة خلفية جديدة (اختياري — خاوي = نفس الاستوديو).
   - `max_chars`: `0` عادي | مثلا `800` إلا بغيتي **تجربة قصيرة** ديال دقيقة.
3. **Run workflow** ✅ و استنا (شوف الأسفل المدة).
4. ملي يسالي: حل الـ run → لقا **`podcast_package`** فالتحت (Artifacts) → حملو.
   - داخل الباكاج: **podcast_final.mp4** (الفيديو الكامل) + master.mp3 + subs.srt + preview jpgs.

## ⏱️ شحال من الوقت كياخد؟ (تقريبا على السيرفر المجاني)

| المرحلة | سكريبت 10 دقايق (~10k حرف) | سكريبت 20 دقيقة |
|---|---|---|
| 🎙️ استنساخ الصوت XTTS | ~30-60 د | ~60-120 د |
| 📜 الترجمة + التحليل | ~5-10 د | ~10-20 د |
| 🎬 الريندر | ~10-15 د | ~20-30 د |
| **المجموع** | **~1 ساعة** | **~2-3 ساعات** |

⚠️ الحد الأقصى ديال الجوب فGitHub هو حوالي **6 سوايع**. إلا كان السكريبت طويل بزاف
(ساعة+ = ساعة و ربع بحال الأنوناكي)، قسّمو على جوج حلقات أو خفض المدة.

## 🎙️ على الصوت

- الصوت كيتستنسخ من `voice_ref.wav` (تقنية Coqui XTTS v2). كيقرب بزاف لصوت البودكاست الأول — التمبري نفسو.
- بغيتي تجرب صوتك نتا؟ بدل `voice_ref.wav` بمقطع ديال صوت نقي 20-60 ثانية (مونو، بلا موسيقى).
- الصوت المستنسخ طبيعي ولكن ماشي 100% بحال الأصل — دير تجربة قصيرة بـ `max_chars=800` و سمع النتيجة.

## 🛠️ إلا وقع مشكل

- حل الـ run الفاشل → كليكي على الجوب → **شوف الـ logs** → صيفط سكرينشوت.
- الأغلب كيكون: تصويرة ما تحملاتش، أو الذاكرة (سكريبت طويل بزاف)، أو نسخة مكتبة تبدلات.

بالتوفيق أ صاحبي! 🎙️🔥
